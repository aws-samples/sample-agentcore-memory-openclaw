# Plant notes skill (local stub)

Record and retrieve per-plant observations, care history, and growth notes so
Sprout can give continuous, personalized advice.

> This is a minimal local stub created by the deploy-time skill installer as a
> fallback when the ClawHub `plant-notes` skill could not be resolved. Replace
> it with the real skill (or let the installer overwrite it) when available.

## Capabilities
- Append dated observations to a plant's history.
- Retrieve past notes for a given plant.
