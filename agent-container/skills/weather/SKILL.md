# Weather skill (local stub)

Look up current weather conditions and forecasts so Sprout can warn about frost
and check growing conditions for the gardener's zone.

> This is a minimal local stub created by the deploy-time skill installer as a
> fallback when the ClawHub `weather` skill could not be resolved. Replace it
> with the real skill (or let the installer overwrite it) when available.

## Capabilities
- Report current conditions for a location.
- Provide short-term forecasts and frost warnings.
